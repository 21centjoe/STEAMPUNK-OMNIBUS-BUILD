# The Grand Steampunk Omnibus Compendium - Protocol 252

Welcome to the unified single-directory build of the steampunk archives, quantum card templates, and experimental comps. This repository bundles four distinct interactive web modules[cite: 1, 2, 3, 4] under a cohesive brass-and-rivet aesthetic.

## Included Modules

* **The Omnibus Quest Casino (`the_omnibus_quest_casino.html`)**: An interactive arcade simulation featuring quantum dodecahedron resonance, mechanical dice rolling, custom card forging, a sandbox script editor, and Gemini Coin economics[cite: 1].
* **Omnibus Card Template (`gemini-code-1789742363325.html`)**: A 3D holographic parallax card viewer featuring rotating gyroscopes and interactive quantum cores[cite: 2].
* **The Eco-Steampunk Digital Omnibus (`eco_steampunk_digital_omnibus.html`)**: A multi-volume digital book covering temporal archives, Pecos River frontiers, and stellar ark simulation protocols[cite: 3].
* **The Grand Master Archive (`experimental_project_digital_booklet.html`)**: An interactive digital booklet indexing fourteen experimental logs, test evaluations, and telemetry metrics[cite: 4].

## Running Locally

To run this build locally:

1. Place all `.html` files (`index.html`, `the_omnibus_quest_casino.html`, `gemini-code-1789742363325.html`, `eco_steampunk_digital_omnibus.html`, `experimental_project_digital_booklet.html`) alongside this `README.md` in the same directory.
2. Open `index.html` in any modern web browser.
